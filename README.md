# Pinokio

### A browser for running AI apps on your computer

Pinokio is a desktop application that lets you install and run any AI application locally with a single click. Think of it as an app store for AI tools — from image generators to voice cloners to code assistants.

<br>

---

## Features

| | |
|:---|:---|
| **One-Click Install** | Complex AI setups reduced to a single button press |
| **App Discovery** | Browse a curated library of AI tools and creative applications |
| **Isolated Environments** | Each app runs in its own sandbox — no dependency conflicts |
| **Script Automation** | Powered by Pinokio scripts for repeatable, shareable installations |
